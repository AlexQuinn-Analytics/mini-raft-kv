# MiniRaftKV

A fault-tolerant distributed key-value store built in Java using the Raft consensus algorithm.

## Goals

- Leader Election
- Log Replication
- Majority Commit
- Write-Ahead Logging
- Crash Recovery
- Network Partition Testing
